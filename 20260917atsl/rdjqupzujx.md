# 初诊患者须知

> 更新时间：2026-09-17 (UTC+8)

患者须知

**初诊患者需完成以下检查，才能找出您不孕的原因：**

****

1. B超检查和妇科检查排除子宫、阴道、宫颈畸形。

2. 女性性激素和甲功检查。

3. 女性输卵管检查。

4. 男性精液及精浆抗体检查。

5. 月经中期B超检查卵泡和子宫内膜情况。

检查前注意事项

1.女性患者B超检查前请先排尿。

2.女性性激素和甲功检查需来月经第2~4天，上午8点~10点，空腹抽血。

3.女性输卵管检查需月经干净后3~5天，周一至周五上午就诊。检查前3天无性生活，当天B超子宫内膜厚度小于8毫米，无阴道炎症，体温37.2度以下，才可安排输卵管造影。

4.男性精液及精浆抗体检查，需排精后2~7天内，在我科取精室手淫方式取精。周一至周五检查，上午10点以前，下午4点以前检查。

5.月经中期B超检查卵泡和子宫内膜情况，如果月经规律，从来月经起，第11或12天检查。如果月经不规律，听从专家安排即可。

6. 每次看病（包括咨询病情及看非当日化验结果），请先挂号（本中心门诊大厅），如果安排您B超检查，挂号同时交费。

7.请出示您挂的号、病历本在病案室门口排队，听从工作人员安排依次就诊。

8.准备接受“人工授精”或“试管婴儿”助孕的夫妇，请提交你们的身份证、结婚证的复印件，医院将存档。

9.为避免影响当日诊疗计划，特别是需行“B”超检查的患者，请您上午就诊。

10.我科周一至周五全天应诊，周六、周日上午应诊（只监测卵泡其它检查不能做）。

11.为避免发生诊治错误，电话中不提供治疗意见，请配合。**电话：0311—86095350**
